# 🗄️ Database Backup Windows Service

A C# Windows Service that automatically creates full backups of a SQL Server database at a configurable time interval.

## 🚀 Features

- 🔄 Automatic SQL Server database backups
- ⏱️ Configurable backup interval
- 📁 Configurable backup and log folders
- 🕐 Timestamped .bak files
- 📝 Service and backup logging
- ⚠️ Exception handling
- ⚙️ Configuration through App.config
- 🪟 Windows Service support

## 🛠️ Technologies

- C#
- .NET
- Windows Services
- SQL Server
- ADO.NET
- System.Timers.Timer
- App.config
